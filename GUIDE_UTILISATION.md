## Introduction

La Suite de Gestion Commerciale SAMASSA TECHNOLOGIE est une application web professionnelle conçue pour simplifier la gestion de vos documents commerciaux et techniques. Cette application vous permet de créer, gérer et imprimer facilement vos factures, reçus, devis et fiches d'intervention directement depuis votre navigateur.

**Caractéristiques principales :**

- Création rapide de documents professionnels
- Calculs automatiques des montants TTC/HT
- Stockage local sécurisé de vos données
- Fonctionnement hors ligne (PWA)
- Impression directe et export PDF
- Interface 100% en français
- Devise Franc CFA (F CFA)
- Optimisation mobile pour iPhone et Android

## Installation et Accès

### Accès à l'Application

L'application est accessible via votre navigateur web à l'adresse fournie par SAMASSA TECHNOLOGIE. Vous pouvez y accéder depuis :

- **Ordinateur** : Chrome, Firefox, Safari, Edge
- **Smartphone** : Safari (iPhone), Chrome (Android)
- **Tablette** : Tous les navigateurs modernes

### Installation sur Mobile (PWA)

Pour installer l'application sur votre téléphone :

**iPhone (Safari) :**
1. Ouvrez l'application dans Safari
2. Appuyez sur le bouton de partage (carré avec flèche)
3. Sélectionnez "Sur l'écran d'accueil"
4. Confirmez en appuyant sur "Ajouter"

**Android (Chrome) :**
1. Ouvrez l'application dans Chrome
2. Appuyez sur le menu (trois points)
3. Sélectionnez "Installer l'application"
4. Confirmez l'installation

Une fois installée, l'application apparaîtra comme une application native sur votre téléphone et fonctionnera hors ligne.

## Module Factures

### Créer une Facture

1. Cliquez sur **"Factures"** dans la navigation
2. Cliquez sur le bouton **"Nouvelle Facture"**
3. Remplissez les informations du client :
   - Nom du client
   - Email
   - Adresse
   - Téléphone

4. Ajoutez les articles/services :
   - Description
   - Quantité
   - Prix unitaire
   - Le montant total s'ajoute automatiquement

5. Configurez la facture :
   - Date de facture
   - Date d'échéance
   - Taux de TVA (par défaut 18%)
   - Notes supplémentaires

6. Cliquez sur **"Enregistrer et Aperçu"** pour voir la facture

### Aperçu et Impression

Une fois la facture créée, vous pouvez :

- **Imprimer** : Cliquez sur "Imprimer" pour imprimer directement
- **Télécharger PDF** : Cliquez sur "Télécharger PDF" pour sauvegarder en PDF
- **Éditer** : Cliquez sur "Éditer" pour modifier la facture

### Tableau de Bord des Factures

Le tableau de bord affiche :

- Liste de toutes vos factures
- Montant total par facture
- Date de création
- Recherche et filtrage par client ou numéro
- Statistiques : Total, nombre, montant moyen

## Module Reçus de Paiement

### Créer un Reçu

1. Cliquez sur **"Reçus"** dans la navigation
2. Cliquez sur **"Nouveau Reçu"**
3. Remplissez les informations :
   - Nom du client
   - Montant reçu (en Francs CFA)
   - Date du paiement
   - Méthode de paiement (Espèces, Chèque, Virement, etc.)
   - Description du paiement

4. Le montant s'affiche automatiquement en lettres (ex: "Cent mille francs")

5. Cliquez sur **"Enregistrer et Aperçu"**

### Impression et Sauvegarde

- **Imprimer** : Imprimez directement le reçu
- **Télécharger PDF** : Sauvegardez le reçu en PDF
- **Copier** : Copiez le contenu pour l'utiliser ailleurs

---

## Module Devis

### Créer un Devis

1. Cliquez sur **"Devis"** dans la navigation
2. Cliquez sur **"Nouveau Devis"**
3. Remplissez les informations du client
4. Ajoutez les articles/services (comme pour les factures)
5. Définissez la validité du devis :
   - Date du devis
   - Date limite de validité

6. Configurez le taux de TVA
7. Cliquez sur **"Enregistrer et Aperçu"**

### Gestion des Devis

Le tableau de bord des devis vous permet de :

- Voir tous vos devis en attente
- Suivre les montants
- Rechercher par client
- Supprimer les devis expirés
- Imprimer ou télécharger en PDF

---

## Module Fiches d'Intervention

### Créer une Fiche d'Intervention

1. Cliquez sur **"Interventions"** dans la navigation
2. Cliquez sur **"Nouvelle Intervention"**
3. Remplissez les informations du client :
   - Nom
   - Téléphone
   - Email
   - Adresse

4. Décrivez l'intervention :
   - **Problème diagnostiqué** : Décrivez le problème rencontré
   - **Solution apportée** : Décrivez la solution mise en place
   - **Technicien** : Nom du technicien qui a effectué l'intervention
   - **Statut** : En attente, En cours, Terminée, En suspens

5. Définissez les dates :
   - Date d'intervention
   - Date de completion (optionnel)

6. Renseignez les coûts (optionnel) :
   - Coût estimé
   - Coût réel

7. Ajoutez des notes supplémentaires si nécessaire
8. Cliquez sur **"Enregistrer et Aperçu"**

### Suivi des Interventions

Le tableau de bord affiche :

- Liste de toutes les interventions
- Statut de chaque intervention (couleur codée)
- Technicien responsable
- Statistiques : Total, en cours, terminées

## Fonctionnalités Avancées

### Stockage Local et Synchronisation

Toutes vos données sont sauvegardées localement sur votre appareil. Cela signifie que :

- Vous pouvez accéder à vos documents hors ligne
- Vos données ne sont jamais perdues
- Aucune connexion internet n'est requise pour créer des documents

### Recherche et Filtrage

Chaque tableau de bord inclut une barre de recherche pour :

- Rechercher par nom de client
- Rechercher par numéro de document
- Filtrer les résultats en temps réel

### Export et Impression

Vous pouvez :

- **Imprimer directement** : Utilisez la fonction d'impression de votre navigateur
- **Télécharger en PDF** : Sauvegardez les documents en PDF pour archivage
- **Copier le contenu** : Copiez le texte pour l'utiliser ailleurs

### Numérotation Automatique

L'application génère automatiquement des numéros uniques pour chaque document :

- **Factures** : FAC-YYYY-XXXXX
- **Reçus** : REC-YYYY-XXXXX
- **Devis** : DEV-YYYY-XXXXX
- **Interventions** : INT-YYYY-XXXXX

## Dépannage

### L'application ne charge pas

**Solution :**
1. Rafraîchissez la page (Ctrl+R ou Cmd+R)
2. Videz le cache du navigateur
3. Vérifiez votre connexion internet
4. Essayez avec un autre navigateur

### Les données ne se sauvegardent pas

**Solution :**
1. Vérifiez que vous avez rempli tous les champs obligatoires
2. Vérifiez que votre navigateur accepte les cookies
3. Vérifiez l'espace disponible sur votre appareil
4. Videz le cache du navigateur

### L'impression ne fonctionne pas

**Solution :**
1. Vérifiez que votre imprimante est connectée
2. Essayez d'imprimer en PDF d'abord
3. Utilisez un autre navigateur
4. Vérifiez les paramètres d'impression

### L'application fonctionne lentement

**Solution :**
1. Fermez les autres onglets
2. Videz le cache du navigateur
3. Redémarrez votre navigateur
4. Vérifiez votre connexion internet
