## ✨ Fonctionnalités Principales

### 📄 Gestion de Factures
- Création rapide de factures professionnelles
- Calcul automatique HT/TTC avec TVA configurable
- Numérotation automatique des factures
- Export PDF et impression directe
- Tableau de bord avec statistiques

### 💰 Reçus de Paiement
- Génération de reçus professionnels
- Conversion automatique du montant en lettres
- Suivi des paiements par méthode
- Historique complet des reçus

### 📋 Devis Commerciaux
- Création de devis avec validité
- Calcul automatique des montants
- Gestion du statut des devis
- Export et impression

### 🔧 Fiches d'Intervention
- Documentation complète des interventions informatique
- Suivi du problème et de la solution
- Gestion du statut (en attente, en cours, terminée, en suspens)
- Suivi des coûts estimés vs réels
- Assignation aux techniciens

## 🚀 Caractéristiques Techniques

- **Interface 100% en français** - Navigation et documents entièrement en français
- **Devise Franc CFA** - Tous les montants en F CFA
- **Stockage Local** - IndexedDB pour le stockage sécurisé des données
- **PWA (Progressive Web App)** - Installation mobile et fonctionnement hors ligne
- **Responsive Design** - Optimisé pour desktop, tablette et mobile
- **Design Professionnel** - Interface élégante et cohérente
- **Impression Directe** - Imprimez vos documents en un clic
- **Export PDF** - Téléchargez vos documents en PDF

## 🛠️ Technologies Utilisées

- **Frontend** : React 19, TypeScript, Tailwind CSS 4
- **Backend** : Express.js, tRPC
- **Base de Données** : MySQL/TiDB avec Drizzle ORM
- **Stockage** : IndexedDB (local), S3 (cloud)
- **PWA** : Service Worker, Web App Manifest
- **Build** : Vite, esbuild

## 📱 Installation

### Accès Web
L'application est accessible directement via votre navigateur web.

### Installation Mobile (PWA)

**iPhone (Safari) :**
1. Ouvrez l'application dans Safari
2. Appuyez sur le bouton de partage
3. Sélectionnez "Sur l'écran d'accueil"
4. Confirmez

**Android (Chrome) :**
1. Ouvrez l'application dans Chrome
2. Appuyez sur le menu (trois points)
3. Sélectionnez "Installer l'application"
